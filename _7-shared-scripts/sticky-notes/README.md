# Sticky notes

The published bundle is `assets/annotations/sticky-notes.json`. It currently contains no notes. Do not add sample messages to that file. Graphics has one overview note; Docs can have multiple notes for its documents. Authors choose **New note (draft)** in General Constructor to set text, color, rotation, and size before placing a note on either page. The draft has no surface anchor and stays in memory until placement. Authors export the complete bundle, review it, then replace the published JSON in the repository. This module does not publish automatically.

`mountStickyNotes({pageId, root, settings, signal})` returns `{constructorElement, readBundle, importBundle, dispose}`. Sticky notes mount on Graphics and Docs only. Both pages keep their scene-attached notes and authoring controls; the note dock is no longer draggable. The General Constructor display preference switches the dock between a small note preview and “Click to read.” Other pages do not mount the sticky-note UI. Scene adapters use stable source-local anchors and clean up their nodes, listeners, textures, and geometry.

Bundle version 1 is `{ "version": 1, "notes": [...] }`. Each note has `id`, `pageId`, `text`, `color` (`#rrggbb`), `rotation` (degrees), `size`, and `anchor: {surface, triangle, bary}`. Legacy anchors use a scene mesh, triangle index and three barycentric coordinates. New flat anchors also carry `plane: {point, normal, tangent}` in the stable target's local coordinates; they keep the original triangle and bary fields for v1 compatibility. Validation bounds note counts, text, values, and total size. Import merges by note ID. `readBundle` and export include every page's notes and exclude read history.

A placed note can also have an optional `attachment: {name, url}`. General Constructor's **Import attachment** accepts a PDF, raster image, DOCX/PPTX/XLSX, ODT/ODP/ODS, RTF, TXT, or MD through the local review server (20 MB maximum). Select a placed note before importing; the unplaced appearance draft has no attachment. Files are stored under `_6-docs/documents/`, while bundles store root-relative `/_6-docs/documents/` URLs so they work from every page. The focused reader previews image/TXT/MD attachments and links to every original, including Office documents. Imported PDFs also retain `pageImages`, `pageCount`, and `coverFirst` when Poppler renders page previews: the reader then offers two-page spreads, page arrows, single-page mode, and an optional standalone cover. If page images are unavailable, the full original PDF opens in an embedded reader. PDF page previews are capped at 120; the original link retains every page. Export the bundle and include the referenced files in publication; local import does not publish either one.

The first local edit saves a complete draft bundle in `site.sticky-notes.v1`. On load, a valid local draft replaces the published bundle as a whole, so a locally deleted published note stays deleted. If storage fails, the in-memory draft remains exportable. Read history lives under `site.sticky-notes.dismissed.<pageId>` and compares a fingerprint of the note's current content and anchor; editing a note makes it unread again.

The unplaced appearance draft is also stored in `site.sticky-notes.draft.v1`, so navigating between pages keeps the entered text and appearance. On Graphics or Docs, choose **Place new note** and click a visible scene surface. Scene controls are suspended during placement and while an appearance field has focus, then restored to their prior state. **Cancel placement** and Escape leave the draft or existing attachment intact. Clicking the dock opens the page's note in its reader; Arrow Down opens the note list.

Click a placed note to open its nonmodal reader. The reader has Previous/Next, **Edit in Constructor**, and **Close** controls. Escape or a click outside the reader closes it; Constructor interactions leave it open so edited text and color can be reviewed live.

Graphics and Docs notes use visible mesh hits and cached bounds; rendering follows source transforms without rescanning vertices. Generic surfaces use stable hashes derived from names and same-named sibling order. The book uses separate closed proxy and open detail meshes; a note on one is not automatically remapped to the other. Constructor warns about missing source attachments. No borrowed scene geometry or materials are disposed by the adapters.

## About cube

The About icon is available with zero notes. Click it to hide/show notes, or drag it onto the cube to open a text/color/size/rotation draft dialog. Place commits the draft; Cancel and Escape leave no new note. Creating a note reveals notes if they were hidden. Clicking a visible note opens the shared reader, where **Edit in Constructor** selects it. The existing v1 bundle and Graphics behavior are retained.

New About notes use a flat plane local to a named supporting group in the face's authored space. Placement clears nearby relief over the largest permitted rotated note footprint using visible mesh hits and cached bounds; the saved plane follows support and face movement. Procedural meshes can be picked if they belong to a stable named support. New Fish-scale notes use the same plane clearance path and follow the moving mount. The Fish-scale semantic proxy remains available for existing triangle/bary notes, so saved notes keep following its flip. Existing GLTF and semantic triangle/bary anchors retain their world-transform and morph behavior. Instanced meshes remain unsupported. Invalid drops display a short visible message. Original model geometry, materials and GPU sources are unchanged.
