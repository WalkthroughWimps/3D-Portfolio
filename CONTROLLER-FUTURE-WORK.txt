RESPONSIVE / MANUAL QA

   At portrait and roughly 1024-pixel-wide test sizes, the review-only Settings
   panel overlaps the enlarged controller and parts of the controller extend
   beyond the viewport before the first review gesture establishes the final
   camera pose. Decide later whether review mode needs a dedicated mobile layout.
   The in-app browser and external Chrome were compared; this environment did
   not expose Visual Studio Code's embedded preview for a separate comparison.

   configured for prefers-reduced-motion: reduce. The reduced-motion branch and
   explanatory prompt were source-reviewed, but this environment did not expose
   a reliable runtime emulation control for that preference.
