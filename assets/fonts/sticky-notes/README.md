# Sticky-note handwriting fonts

- `MattHandwriting.otf`: user-supplied font copied unchanged from the provided
  `MattHandwriting.otf` on October 29, 2026. The original was not modified.
- `Caveat.ttf`: variable Caveat font from the official Google Fonts repository,
  https://github.com/google/fonts/tree/main/ofl/caveat . Its SIL Open Font
  License is retained in `Caveat-OFL.txt`.
- `Kalam-Regular.ttf`: regular Kalam font from the official Google Fonts
  repository, https://github.com/google/fonts/tree/main/ofl/kalam . Its SIL Open
  Font License is retained in `Kalam-OFL.txt`.

Fonts are served locally. The sticky-note appearance helper loads the selected
font and refreshes canvas text after it becomes available; a system font remains
available as a fallback.
