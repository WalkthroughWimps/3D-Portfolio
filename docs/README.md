## Editing and saving

Settings, authoring drafts, project files and the public website are different layers. A saved browser preference does not change the source default. A browser draft does not become published content merely because it survives reload. Use the feature's explicit export or local project-save workflow, then review the resulting files. Publication is a separate action.

Before editing existing files, follow [AGENTS.md](../AGENTS.md) and reserve the complete intended file set. Preserve open tabs with unsaved drawings or layouts. Do not use a browser-storage reset as a way to apply source changes.
