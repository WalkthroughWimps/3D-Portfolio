# Gear sizing, pin diagram and Layers refinement — October 18, 2026

This completes the bounded follow-up to the user's three Gear art/Layers images. It supersedes the control placement, gear sizing and column proportions in the prior scroll handoffs. No shared cube, source GLB, global settings, Oddio source or user artwork was changed.

## Changes

- Large gear and Small gear have separately labelled sections with a divider. Large size, Fit pane, Compact and Roll inside are directly below the large choices. The former ten-button pin grid is a diagram of the selected small gear, with selectable numbered holes. Its tooth count/profile updates with the selection, and a readout identifies the pin, closure laps and safe small-size limit. Number keys 1–0 still select pins. Y focuses Large size, Shift+Y Small size and U Auto speed.
- New/edited setups store independent integer `largeTeeth` and `smallTeeth` counts. They share the guide's pitch, so moving one size slider preserves its partner's physical size until a clearance limit requires the small gear to shrink. That limit is visible on the slider/readout. All six guides allow inside rolling, and all nine roller profiles remain scalable rather than swapping to a different catalogue. Shape changes choose a useful multi-lap pair. Circle presets remain convenient initial sizes.
- Inside clearance uses the guide's smallest corner curvature and an upper bound on roller curvature, with conservative allowance for the Plus recesses. Fit pane centres the complete mechanism and adjusts the guide to its available radius. Compact targets a smaller envelope; an excessively large outside roller is reduced if necessary to fit. Outside manual sizing may deliberately extend beyond the pane, preserving the existing clipped-art workflow.
- Arc-length contact and integer closure remain exact. Samples cover the full closing period, with 2,400–3,999 segments, rather than truncating a longer trace at a fixed progress index. Partial render, Keep partial and saved traces use the same sample count. The existing 4,000-point restore limit is retained. Small rendered pin holes scale with roller radius.
- Existing completed drawings remain ordinary editable pencil objects. Existing legacy gear setups keep their previous geometry until edited; the first gear change converts the setup to independent counts. Restore/history preserve the new fields alongside the existing schema. Complete traces remain a single Undo operation.
- Both logical scroll surfaces are 546 × 900 pixels (textures 1092 × 1800); viewport-limited physical height and compact-layout height allowance are increased. Layers now receives 276px of the left tablet, leaving about 238px for Gear art before its own gutter. Equal outer scroll widths and rigid rods are retained.
- Layout reserves a bottom action strip so Accessible controls cannot cover the last gear action. Padlocks use path-only SVG geometry, matching the tablet rasterizer's supported shapes, so the lock body is visible as well as its shackle.
- Group disclosures use larger SVG chevrons. Children indent by 24px per level and use a filled double-diamond marker. Row and toolbar reorder arrows are removed; dragging and existing ordering keyboard commands remain available. Pane lock/delete targets are larger; lock uses an SVG padlock and delete uses red × styling.
