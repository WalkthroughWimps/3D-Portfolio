# Notes fixed-pixel tablet screens - October 18, 2026

Supersedes the projected-HTML display method in the two scroll-tablet handoffs. This is a Notes-owned change; shared host, registry, settings schema, other face implementations and source model were not edited.

## Display choice and implementation

The Videos screen helper (`_7-shared-scripts/scene/screen-surface.js`, `applyScreenCanvasTexture`) and Games cabinet (`_4-games/games.js`, `setupScreenCanvas`) both draw onto a fixed canvas and map its texture onto screen geometry. Notes now uses that approach. CSS perspective transforms on the individual native controls were removed from the displayed screens.

- The left Gear/Layers screen is **1092 x 1440 pixels**, laid out at 546 x 720 logical pixels. Drawing tools is **760 x 1440 pixels**, laid out at 380 x 720. These framebuffer sizes never change with camera motion, viewport size or zoom. Both screens retain their aspect ratios and scale uniformly. Layout sources use the same columns at every viewport width; all physical controls belong to one image on each rigid rectangle.
- `tablet-screen.js` paints integer-aligned boxes, icons, text, checkboxes, ranges, fields and scrollbars. The original DOM/controllers remain authoritative for control behavior and accessible names/keyboard semantics. Their untransformed layout stays off screen, while the canvas pixels are shown by the existing two screen meshes. Native number/name editing temporarily positions the actual field over the display, preserving caret, IME, selection and existing commit handlers. Enter commits numeric edits; Escape restores the starting numeric value. Rename retains its existing Enter/Escape behavior.
- A screen-plane ray maps pointer positions to the immutable logical grid. Buttons, palette, sliders, wheel/scrollbar scrolling, layer clicks/modifiers/row dragging and gear drawer drops forward to the existing controllers. Synthetic layer drags retain pointer capture on the real display canvas; trusted native DOM drags keep their existing capture behavior. Source keyboard focus is revealed in the appropriate scroller and painted on the screen.
- Source changes coalesce and use a content/control/scroll fingerprint before painting. Repaints are capped at 30 Hz; camera-only movement changes mesh transforms without repainting or uploading the UI textures. The sampled fixture repaints were generally a few milliseconds (roughly 2-7 ms on this host), not a low-end-device performance guarantee. No extra production animation loop, HTML screenshot service, foreignObject rasterization, image copying loop or new dependency was added.
- Transparent, unlit, front-facing screen materials render after artwork so controls remain clear. Blank screens are retained while opening/folding. Canvas textures belong to the reusable workspace and dispose once; the rig borrows them and owns its screen geometry/materials. Detach unbinds screen input/capture; suspend/disable/focus loss close native editing and release input.
- Layout fits all four perspective corners, rather than only clamping the projected center. It preserves the framebuffer aspect while keeping the display within its available rectangle as the face turns. The frame/arms still share the face carrier. The old homography helper now anchors native text fields; it no longer transforms displayed DOM controls.

## Focus and reversible motion

- Continuous tablet focus waits **1.5 seconds**, then starts the arms immediately; the old redundant lift portion no longer delays arm reach. Opening/folding speed controls remain linked or independent as before.
- Tablet focus enters within about **23 degrees** of front and retires beyond about **31 degrees**, with hysteresis. The drawing face can remain focused over its wider existing angle. These limits make the tablets start leaving before extreme perspective angles.
- Folding/reopening uses the same continuous progress value. Returning while the arms are still out reverses their course without another dwell or resetting their pose. A fully stowed assembly starts a fresh dwell.
- The glass begins lifting with face approach before the tablet timer. It stays fully extended until the arms are completely stowed, then lowers smoothly toward the face-angle target. The lift reverses from its current position; reduced motion snaps to the appropriate state. Independent return/lowering travel is about .25/.35 seconds respectively, with the existing .18-unit extension.
